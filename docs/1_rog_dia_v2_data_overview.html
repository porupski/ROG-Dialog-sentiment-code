The problem, in short

Short Slovenian dialogue carries affect, but off-the-shelf parliamentary sentiment models fail on it. Parliament text and parliament speech lift their sentiment signal from long, prepared utterances. ROG-Dialog v2 flips both axes: clips are short, speakers overlap, and the register is colloquial. The goal of this report set is to locate where the sentiment signal still survives, and where it does not.

How the matrix reads from these corpora

Engine — what the matrix is, how the duration study reads it
  • The fine-tune matrix. 3 XLM-R backbones × 7 training-data mixtures = 21 regression models. Each is trained once with the ParlaSent recipe (lr 8e-6, batch 32, 4 epochs, MSE on z-scored labels). Mixtures are S (ParlaSent-SL), P (ParlaSpeech-SI transcripts), R (ROG-Dialog v2 transcripts), their pairs and the triple SPR.
  • What each model produces. Each cell is evaluated on all three held-out test sets. It writes one row per test instance {instance_id, text, gold_scalar, pred_scalar, gold_6cls, pred_6cls, gold_3cls, pred_3cls} to predictions_<source>.jsonl. 63 prediction files total, one matrix run, no model weights kept.
  • The duration / WPS analysis. All duration plots read-and-aggregate those 63 files. For each test row the script joins to the source JSONL on instance_id, pulls duration (s) and word count, computes WPS = words / duration, then bins and scores. Nothing is retrained.
  • Binning. Quantile (equal-count) bins over each test source's own distribution. The envelope line per backbone is the best-mixture value at each bin. Self-labelled cells (xlm-r-parlasent × any mixture containing P, because ParlaSpeech sentiment was auto-generated by ParlaSent itself) are excluded — those measure self-consistency, not transfer.
  • Where to look. Pipeline code is in scripts/6_sent_duration/. Artefacts land under misc/run_results/finetune_20261113_162724/sent_duration/. Regenerate the raw numbers with python3 scripts/6_sent_duration/04_dataset_stats.py.
