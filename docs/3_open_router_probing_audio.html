Prompt (verbatim) — recreate this run

Audio is sent inline as base-64 WAV via OpenRouter's multimodal input_audio content-part; OR routes this to the provider-native audio part (Gemini accepts it directly). Few-shot prepends exemplars as (audio, label) pairs — the exemplar text is NOT shown, only the audio and the gold label. Source: scripts/3_probe_audio/05_run_openrouter_audio.py.

System message (6-class)

You classify Slovenian spoken-dialogue utterances by sentiment. You will receive an audio clip of a short utterance. Listen to the audio (tone, prosody, emphasis, and the words themselves) and choose exactly one label from this list:
- predominantlyNegative
- mixedNegative
- neutralNegative
- neutralPositive
- mixedPositive
- predominantlyPositive

Reply with only the label. No explanation.

System message (3-class) — same wording, label list becomes - negative / - neutral / - positive.

User turn (multimodal content array, per target and each few-shot exemplar)

  {"type": "text", "text": "Utterance:"},
  {"type": "input_audio",
   "input_audio": {"format": "wav", "data": "<base64 WAV bytes>"}}
