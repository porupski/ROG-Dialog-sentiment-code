The hunt for the Slovenian sentiment signal Where does it hide in short spoken dialogue — in the text, or in the audio? Six reports: datasets, two API probes, two local fine-tune tracks, a duration study.

Ivan Porupski — Jožef Stefan Institute. Reports are static HTML, hosted on GitHub Pages. Numbers come from the finetune matrices under runs/from_remote/ and the OpenRouter batches under runs/; pipeline code is in scripts/. See the references at the bottom of each report for cited work.

1.ROG-Dialog v2 — data overview current
Three Slovenian corpora: ROG-Dialog v2 (13.7 k short dialogue utterances), ParlaSpeech-SI (918 k parliamentary speech transcripts), ParlaSent-SL (2.6 k parliamentary text). Modality, splits, label priors, duration + WPS distributions. Read first.
2.OpenRouter — text probing current
Flash / Haiku / GPT-{4o,5,5.6-luna} on ROG transcripts. Flash 0shot W=40 FULLROG = 0.621 F1_3; 6-cls peaks at W=10 then plateaus; 3-cls-native beats 6-cls-collapsed by +0.13 at W=40. Context envelope maps over words × W and WPS × W.
3.OpenRouter — audio probing shelved
Gemini Flash and Carbon on raw ROG audio, 170-subset. 0shot matches text; few-shot destroys the audio prompt. Kept for reference; the audio deliverable goes through local fine-tune (Report 5).
4.Local — text fine-tuning current
3 XLM-R backbones × training mixtures from S/P/R. Best cell: xlm-r-parlasent × R_full iso = 0.469 F1_3 on rog-full test. Context HURTS local fine-tunes (opposite of Flash) on this training-data scale — scale + mix is the next lever.
5.Local — audio fine-tuning up next
The last unexplored axis. Plan: three audio backbones iso, then fine-tune on rog_2s / rog_full / parlaspeech-matched-to-rog, eval on rog-full + parlaspeech-matched, then redo the context sweep for audio. Target: beat the 0.469 text ceiling.
6.Sentiment signal across duration current
Full-ROG rebin: Flash 0.42 → 0.77 F1_3 from sub-1 s to 4–8 s; context lifts the sub-1 s floor by +0.09. Proportional-duration hypothesis ruled out — at matched 4–8 s the ROG-vs-parliament gap is domain, not length.

What we think works — recipes so far

Text recipe (production-plausible).

  1. LLM route (best F1, low ops). Flash 0shot 3-cls, context window W ∈ [20, 40] words per side, same prompt as Report 2's verbatim block. F1_3 ≈ 0.62 on rog-full. Cheap ($~2 per 2233-instance eval). Do not run 6-cls and collapse — scheme sensitivity loses 0.13 F1 (Report 2).
  2. Local route (ops-friendly, if LLM API is off the table). xlm-r-parlasent × R_full iso, no context augmentation (context hurts — Report 4). F1_3 ≈ 0.47 on rog-full. Open gaps: training-data scale, uncapped per-source mixing.
  3. Duration note. Do not filter sub-2 s clips from training. They are 81 % of test and matter. Context compensates for sub-1 s floor (+0.09 F1 from iso to W=40 on Flash sub-1 s band — Report 6).

Audio recipe (open — work in progress).

  1. Iso benchmarks on three audio backbones (wav2vec-family / WavLM / Whisper-encoder + head per Report 5 plan).
  2. Train sweeps: rog_2s, rog_full, parlaspeech-matched-to-rog (resampled to mimic ROG duration + WPS). Eval on rog-full and parlaspeech-matched-to-rog.
  3. Then context sweep W ∈ {10, 20, 30, 40} — the audio analogue of Report 2's Flash context sweep.
  4. Target: beat the 0.469 local text ceiling on rog-full. A genuine modality lift + a working context story would be the deliverables.
