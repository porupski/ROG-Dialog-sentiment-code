Where does the sentiment signal live? Short Slovenian dialogue clips (ROG-Dialog v2), text vs audio. 170-instance speaker-disjoint evaluation set; ordinal 6-class labels and collapsed 3-class polarity.

1 · Text, via API

Gemini Flash and Claude Haiku, zero-shot and 18-exemplar few-shot. Few-shot helps text everywhere. Best: Flash few-shot at F1 0.607 (3-class). Haiku is ~13× cheaper for a 0.07 F1 penalty.

  • Total API cost for all 8 configs × 170 instances: ~$0.68 (list).
  • Early collapse of Flash-fshot-3cls (F1 0.21) was fixed by raising max_tokens 50 → 500 so the model's mandatory reasoning had room.

2 · Text, via fine-tuned XLM-R

Three XLM-R backbones × seven data mixtures (parliament text, parliament speech transcripts, dialogue). Pure parliament → dialogue transfer is broken. ROG alone is too small — plain backbones collapse to "neutral". Mixing all three sources (SPR) is the only path that holds positive R² on dialogue.

3 · Audio, via API

Gemini Flash and Gemini Carbon on ROG audio. Flash 0-shot hits F1 0.581 on 3-class — within 0.03 of the text ceiling. Few-shot destroys audio: Flash's own judgements sign-flip (Krippendorff α = −0.10 shot-flip, 6-class).

  • Carbon shot-flip α = +0.61 — only audio model that doesn't collapse under few-shot, but still loses F1.
  • Both runs were on 50%-off promo pricing; list price would double (~$2.47 → ~$4.93 at this batch size).
  • Recommendation: ship audio zero-shot only for now. Re-encode exemplars as audio+verbal-label pairs before retrying few-shot.

Where to go next

Deliverable is a transformer speech-sentiment model, not an API pipeline. Live recipe: XLM-R-ParlaSent × SPR mixture, text modality. Audio doesn't beat text yet on 6-class. Fusion and a dedicated audio encoder (wav2vec-family) are open options pending bossman's call.

4 · Bonus — speech rate turns out to matter

Follow-up pass on the ROG test set under a speech-rate control (words per second). The "longer clips carry more sentiment signal" effect lives in the slow-to-moderate band (≤ ~2.7 wps) and vanishes or inverts above it. In fast speech, duration stops mattering.

Conclusion — clip-curation filter. Length alone isn't enough. For a clean training / evaluation set with potent sentiment signal, the filter should be:
  • Length: 10–40 words or 2–20 s audio (existing).
  • Speech rate: gate on WPS ≈ 1.5–3.0 (the band where longer clips measurably carry more sentiment signal; above ~3 wps the signal flattens).
Fast, dense speech (> 3.35 wps) is in the data but doesn't play by the same length rule — worth tagging separately rather than mixing it into a general training pool.
How this was measured
  • ROG-Dialog test (n=434) split into 4 equal-count WPS quartiles.
  • Inside each quartile, duration / word count binned into 3 equal-count sub-bins (~36 instances per bin).
  • Per bin, F1_3 is computed from each matrix cell's predictions; envelope = best-mixture-avg per backbone, self-labelled cells excluded.
  • Shape classification: ρ (Spearman of bin-center vs F1_3) ≥ +0.6 = monotone+, ≤ −0.6 = monotone−, |ρ| < 0.3 = flat, else = weak.
